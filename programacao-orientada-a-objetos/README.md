# Programação Orientada a Objetos

**Trabalho G2 — Lost in the Waves.** Jogo retrô de surfe em Java Swing, com arquitetura MVC e janela construída no WindowBuilder.

O projeto tem um repositório próprio: **[GDaflon/lost-in-the-waves](https://github.com/GDaflon/lost-in-the-waves)**, com o código, os vídeos da partida e os documentos de entrega.
